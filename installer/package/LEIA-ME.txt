MONITOR DE PRODUTIVIDADE
========================

COMO INSTALAR
1. Extraia TODO o conteúdo deste .zip para uma pasta (não execute de dentro do .zip).
2. Dê dois cliques em "Instalar.cmd".
3. Pronto: o programa é instalado para o seu usuário, aparece no Menu Iniciar e na
   Área de Trabalho e fica na bandeja do Windows (perto do relógio).

Não precisa de administrador, de internet nem de ter o .NET instalado.

COMO USAR
- Ctrl+Alt+S  iniciar uma demanda
- Ctrl+Alt+P  pausar / retomar
- Ctrl+Alt+F  finalizar
- Ctrl+Alt+N  escrever uma anotação rápida
Os atalhos podem ser alterados em Configurações. Nessa tela também dá para ativar
o início junto com o Windows e escolher o tema.

COMO DESINSTALAR
Dê dois cliques em "Desinstalar.cmd". Você escolhe se mantém ou apaga seus dados.

AVISO DO WINDOWS (SmartScreen)
O programa não é assinado digitalmente. Se aparecer "O Windows protegeu seu computador",
clique em "Mais informações" e depois em "Executar assim mesmo".

ONDE FICAM OS DADOS
%LOCALAPPDATA%\ProductivityMonitor  (banco de dados e logs)
